# JavaScript DOM Manipulation

This project covers selecting and modifying HTML elements with JavaScript,
handling DOM and user events, and making requests with the Fetch API.

## Tasks

- 0-script.js: change header text color to red
- 1-script.js: change header color to red on click
- 2-script.js: add the class red to header on click
- 3-script.js: toggle header class between red and green
- 4-script.js: add a list item on click
- 5-script.js: change the header text on click
- 6-script.js: fetch and display a Star Wars character
- 7-script.js: fetch and list Star Wars movies
- 8-script.js: fetch and display a French hello
- 100-script.js: add, remove and clear list items
- 101-script.js: translate hello into the selected language
