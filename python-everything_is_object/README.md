# Python - Everything is object

This project explores how Python treats everything as an object:
types, identity, mutability, and how variables reference objects.

## Tasks

- 0-answer.txt: function used to print the type of an object
- 1-answer.txt: function that returns the identifier of a variable
- 2-answer.txt: are a and b the same object (89 and 100)
- 3-answer.txt: are a and b the same object (89 and 89)
- 4-answer.txt: are a and b the same object (b = a)
- 5-answer.txt: are a and b the same object (b = a + 1)
- 6-answer.txt: output of comparing two strings with ==
