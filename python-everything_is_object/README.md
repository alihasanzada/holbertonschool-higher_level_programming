# Python - Everything is object

This project explores how Python treats everything as an object:
types, identity, mutability, and how variables reference objects.

## Tasks

- 0-answer.txt: function used to print the type of an object
- 1-answer.txt: function that returns the identifier of a variable
- 2-answer.txt: are a and b the same object (89 and 100)
- 3-answer.txt: are a and b the same object (89 and 89)
- 4-answer.txt: are a and b the same object (b = a)
- 5-answer.txt: are a and b the same object (b = a + 1)
- 6-answer.txt: output of comparing two strings with ==
- 7-answer.txt: output of comparing two names with is (s2 = s1)
- 8-answer.txt: output of comparing two equal strings with ==
- 9-answer.txt: output of comparing two equal strings with is
- 10-answer.txt: output of comparing two equal lists with ==
- 11-answer.txt: output of comparing two equal lists with is
- 12-answer.txt: output of comparing a list with its alias using ==
- 13-answer.txt: output of comparing a list with its alias using is
- 14-answer.txt: output after list append through an alias
- 15-answer.txt: output after list concatenation through an alias
- 16-answer.txt: output after incrementing an integer in a function
- 17-answer.txt: output after appending to a list in a function
- 18-answer.txt: output after assigning a list in a function
- 19-copy_list.py: function that returns a copy of a list
